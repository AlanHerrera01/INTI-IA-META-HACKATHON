# Local document dossier

AI Agent Studio → Documents accepts a customer/contact/date form, one to eight
quotation items, an explicit tax input and conditions. It prepares a typed plan
using `POST /api/v1/computer/document-tasks`. Preparation grants no execution.
Existing exact-digest approval, paired-device claim, cancellation and durable
no-replay behavior also apply to these tasks.

The host agent needs `python-docx`, `openpyxl` and `reportlab` (install the backend
package's `agent` extra or use the updated source-only agent download). These
packages are not needed in the backend Docker runtime. Existing agent installs
must restart/update their Python source to recognize the new document task.

Approved outputs are fixed names inside a fresh task-UUID folder beneath the
paired root: `cotizacion.docx`, `presupuesto.xlsx`, `cotizacion.pdf`, `resumen.txt`
and `manifest.json`. Inputs cannot specify output paths or execute commands.
The pipeline rejects an existing task folder and never overwrites prior work.
Cancellation retains earlier outputs; recovery prepares a new reviewed draft.

Money is calculated in integer cents. Tax uses the explicitly entered basis-point
rate and half-up rounding; the default is a configurable example, not tax advice.
Excel stores formulas, cached results, a native chart and a reconciliation sheet.
Word fields and the Excel total are reopened and checked; PDF structure and all
output SHA-256 hashes are checked. The manifest binds those files to the approved
plan digest. These are agent-reported checks, not independent desktop vision.

No application is launched, document is signed, email is sent, external service
is called or model plan is generated by this workflow. Office UI control is not
implied by filling the generated Word/Excel files.
