## Recording checklist

- Use `scripts/start_demo.ps1`; leave model calls off unless separately authorized.
- Connect the capability before recording; do not film the `.env` file or clipboard.
- Reset through the confirmation UI and prepare a new mission for each take.
- Keep source labels, unknown results and dependency errors visible.
- Capture actual screens; label any cuts, time compression or replay.
- Use the new report's actual verdict/evidence count if it differs from this script.
